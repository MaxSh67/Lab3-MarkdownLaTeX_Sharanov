## Элементы Markdown

### Заголовки

В Markdown заголовки создаются с помощью символа `#`.

# Пример заголовка H1

## Пример заголовка H2

### Пример заголовка H3

---

### Форматирование текста

- **Полужирный текст** - `**текст**`
- *Курсив* - `*текст*`
- ~~Зачёркнутый~~ - `~~текст~~`
- `Моноширный` - `` `текст` ``

---

### Списки

#### Маркированный список

- Первый пункт
- Второй пункт
- Третий пункт

#### Нумерованный список

1. Первый пункт
2. Второй пункт
3. Третий пункт

#### Вложенный список

1. Основной пункт
   - Подпункт первого уровня
     - Подпункт второго уровня
2. Второй основной пункт

### Блок кода

Пример блока кода с указанием языка:

```csharp
class Program
{
    static void Main()
    {
        Console.Write("Введите первое число: ");
        double number1 = Convert.ToDouble(Console.ReadLine());
        
        Console.Write("Введите второе число: ");
        double number2 = Convert.ToDouble(Console.ReadLine());
        
        double sum = number1 + number2;
        Console.WriteLine($"Результат: {sum}");
    }
}
```

### Block LaTeX
Степени и индексы: $x^2, a_i, x^{10}$

Дроби: $\frac{a}{b}$

Корни: $\sqrt{x}, \sqrt[3]{y}$

Греческие буквы: $\alpha, \beta, \gamma, \delta$

Суммы и произведения: $\sum_{i=1}^n i, \prod_{k=1}^n k$

Матрицы: 
$$
\begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}
$$
